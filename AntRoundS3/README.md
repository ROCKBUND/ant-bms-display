# 蚂蚁 BMS 圆屏 · ESP32-S3 一体板

2026-10-19，v0.7 LVGL 圆屏 UI。用户已确认实物为无触摸版本，显示屏为 GC9A01 240×240，使用侧面三个按键操作。
本次仅修改和交付 Arduino 源码，未编译、未烧录、未实机验证。

## 本版界面

- 首页：黑底、青绿色电量环、抗锯齿数字，电压/电流并排，下方突出显示功率 W。
- 充电动画：有效数据满足电流小于 -0.2 A、且无保护告警时，两段亮色拖尾在已亮的电量弧内顺时针循环。电量弧长度仍由真实 SOC 决定，不随动画虚增。周期 2.6 秒，动画刷新目标约 20 次/秒，实际帧率待实机确认。
- 断线、超过 5 秒无有效数据或退出首页时停止首页流光；无效读数显示 `--`，环恢复暗轨。待机/放电使用静态电量环；电量不高于 15% 时使用红色。保护提示优先于充电提示，并停止流光。
- 详情页：剩余容量、总容量、MOS 温度、单体压差以四块区域排列；底部显示串数与单体最高/最低电压。
- 诊断页：保留蓝牙地址、通信状态、帧数和错误计数。
- 蓝牙选择页：突出显示选中设备，底部文字对应上/中/下侧键；当前无触摸配置不显示触屏按钮。
- **按用户最新要求，不加入新开机画面或开机动画。** 保留原来的 `ANT BATTERY / STARTING...` 简单启动提示。

LVGL 8.3.11 已随工程放在 `src/lvgl/`；项目配置为 `src/lv_conf.h`。不需要另外安装 LVGL，也不要删除或移动 `src` 目录。UI 源码位于 `BatteryUi.h/.cpp`。字体和布局按 240×240 定制；此前设计预览不是实机截图。

当前 `TOUCH_ENABLED=false`：跳过触摸初始化与读取，状态页显示 `Touch OFF`，不会把缺少触摸硬件显示为故障。触摸驱动文件保留在完整工程中，供以后换用触摸版硬件时使用。

v0.6：在首页下方将功率改为独立 POWER 标签和较大的绿色数值（W）。功率=保护板总电压×电流，按整数瓦显示；沿用当前协议的符号约定，正值放电、负值充电，初次使用需与手机 App 核对方向。断线或数据过期显示 `-- W`，不保留旧功率。

当前操作：数据页短按下键翻页，上键或中键进入蓝牙选择；选择页短按下键选设备，中键连接，上键返回。中键长按约 3 秒由硬件控制开关机。无触摸版通过侧键完成操作。

## 打开工程

打开本目录的 `AntRoundS3.ino`，保留同目录所有 `.h`、`.cpp` 文件。

源码文件包括：AntRoundS3.ino、BatteryUi.h/.cpp、Config.h、Cst816Touch.h/.cpp、BoardButtons.h、TouchInput.h、BmsLink.h/.cpp、AntProtocol.h、PairingSession.h，以及完整 `src/` 子目录。解压后直接打开 `AntRoundS3/AntRoundS3.ino`；不要只复制 `.ino`。

需要的外部库：

- GFX Library for Arduino **1.6.9**。
- NimBLE-Arduino **2.5.0**。
- Wire、Preferences、SPI 随 ESP32 开发板包提供。

本仓库不重复分发上述外部库；请在 Arduino IDE 库管理器中安装对应版本。
触摸驱动和 LVGL 已包含在工程中，无需另外安装 IT7259、CST816 第三方库或 LVGL。
商家 FullFunctionTest 基于旧 ESP32 2.0.17 和 GFX 1.4.7；本工程沿用工作区的 ESP32 3.3.10、GFX 1.6.9、NimBLE 2.5.0 源码接口，不需要替换为商家旧库。

## Arduino IDE 设置

下表根据商家硬件参数、示例配置及本机已安装的 3.3.10 菜单核对，尚未经过本工程编译验证。

| 选项 | 值 |
|---|---|
| ESP32 开发板包 | 3.3.10 |
| Board | ESP32S3 Dev Module |
| CPU Frequency | 240MHz |
| USB CDC On Boot | Enabled |
| USB Mode | Hardware CDC and JTAG |
| Upload Mode | UART0 / Hardware CDC（选择板载 USB 对应的端口） |
| Flash Mode | QIO 80MHz |
| Flash Size | 16MB (128Mb) |
| Partition Scheme | 16M Flash (3MB APP/9.9MB FATFS) |
| PSRAM | OPI PSRAM |
| Serial Monitor | 115200，发送命令时带换行 |

Flash 使用 QIO，PSRAM 使用 OPI，两项不要混淆。N16R16 标称 16MB PSRAM；开机串口打印运行时识别的容量。本程序使用 240×40 的 RGB565 绘图缓冲（19,200 字节）和 LVGL 48 KiB 内存池，不依赖整屏 PSRAM 分配。LVGL 仅由 Arduino 主循环调用；BLE 工作任务通过快照提供数据。

正常开关机：按商家文档，长按侧面中间电源键约 3 秒。电源开关由板载硬件控制，程序没有电源保持 GPIO。
若手动上传时找不到下载端口，按住背面 IO0，再按一下 RST，松开 RST 后松开 IO0，重新选择端口。IO0 同时接触摸复位，日常操作请用侧面三个按键。

## 板内引脚

这是板内固定连接，无需按旧 C3 方案接线。

| 功能 | GPIO / 参数 |
|---|---|
| LCD MOSI / SCK | 10 / 3 |
| LCD CS / DC | 2 / 18 |
| LCD RST / BL | 21 / 42，高电平开背光 |
| LCD SPI | HSPI，20MHz |
| Touch SDA / SCL | 8 / 9，100kHz |
| Touch RST / INT | 0 / 11 |
| Touch I2C 地址 | 0x15 |
| 侧面上 / 中 / 下键 | 14 / 15 / 16，低电平按下 |
| 未使用的 TF 片选 | 40，保持高电平 |

本版采用全亮背光 GPIO 控制，不调用商家旧版 LEDC API。
以下触摸说明仅适用于更换为触摸硬件并启用 `TOUCH_ENABLED=true` 后：触摸复位使用开漏方式释放 GPIO0。触摸按固定周期读取 FingerNum 和坐标，关闭自动休眠及长按自动复位；设置会回读检查。仅接受商家示例列出的 CST816S/T/D ID（B4/B5/B6）。初始化失败时串口打印实际 ID，并保留按键和串口操作。

触摸通信错误、无中断都不会被当作“松手”；点击和滑动需稳定松手后触发，长按达到门限时触发一次，拖动不触发蓝牙页按钮。屏幕方向默认与商家完整示例一致，不翻转坐标。若实物方向不同，可在 Config.h 调整 TOUCH_SWAP_XY、TOUCH_MIRROR_X、TOUCH_MIRROR_Y、TOUCH_ROTATION；显示旋转另由 DISPLAY_ROTATION 控制。
当前无触摸版本已将 TOUCH_ENABLED 设为 false，使用侧面按键。

## 使用

开机会先显示 ANT BATTERY / STARTING，当前配置跳过触摸初始化，然后初始化 BLE。沿用原工程的三页电池信息、蓝牙选择、重连和有效报文后保存设备的逻辑。目标仍为 ANT-BLE24CAUB / 24:19:A4:02:23:45。
新开发板有独立的配对存储，旧板的已保存记录不会自动带过来。首次连接前请关闭手机保护板 App 的连接。

以下手势仅适用于触摸版硬件；当前无触摸板不支持。数据页面不显示按钮，也没有隐藏的点击热区。普通轻点不执行操作：

- 左滑：下一页；右滑：上一页。三页循环切换。
- 原地长按约 **0.8 秒**：进入蓝牙选择页并开始扫描；无需先松手。
- 长按触发后必须先松手，再点击蓝牙页按钮；同一次按住或松手不会连续操作。

仅在启用触摸硬件后，蓝牙选择页显示 BACK / SCAN，以及有候选设备时的 PREV / NEXT / CONNECT。触摸版该页使用短按按钮操作，滑动和长按不执行翻页或扫描。默认无触摸版显示侧键提示。

手势门限位于 TouchInput.h：滑动水平净位移至少45像素、时长不超过1.2秒、水平位移至少为垂直位移的1.5倍，途中垂直偏移不超过40像素；长按允许18像素内轻微抖动。松手需连续确认50毫秒，通信中断超过250毫秒会取消当前手势。

侧面按键是当前无触摸板的操作方式，短按松手触发；超过约 0.8 秒的按住不触发界面动作：

| 按键 | 数据页面 | 蓝牙选择页面 |
|---|---|---|
| 上键 GPIO14 | 进入蓝牙扫描 | 返回并恢复之前的连接 |
| 下键 GPIO16 | 翻页 | 下一个设备，可循环 |
| 中键 GPIO15 | 进入蓝牙扫描 | 有设备时连接当前设备；没有设备时重新扫描 |

中键长按约 3 秒仍由硬件开关机；开机时已按住的键不会触发菜单操作。
有候选设备时需要重新扫描，短按上键返回后再次进入扫描。

串口命令保留：`scan`、`back`、`pick N`（从1开始）、`page`、`raw on/off`、`touch on/off`。`touch on` 会输出按下/松手、坐标及芯片 ID，便于核对方向；GESTURE 日志中 0=轻点、1=左滑、2=右滑、3=长按。

程序仅查询保护板状态，不修改保护参数或充放电开关。电量数据来自蚂蚁保护板，未使用本开发板的小锂电池 ADC 作为动力电池电量。TF、RTC、IMU、音频、RGB 未启用。
