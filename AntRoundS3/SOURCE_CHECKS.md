# v0.7 源码交付检查

日期：2026-10-19。

本版未执行 Arduino 编译、其他编译验证、烧录或实机测试。

已完成的源码检查：

- `Config.h`、`BoardButtons.h`、触摸驱动与手势处理、BMS 蓝牙任务和协议解析器，与改动前备份逐字节对比一致。
- `.ino` 内的操作分发、按键、串口和触摸处理函数，与改动前备份一致。
- 内置 LVGL 文件与官方 v8.3.11 下载包逐字节对比一致；另外添加工程配置转发头。
- 本地配置固定为 RGB565、不交换字节，与现有 Arduino_GFX 的像素写入接口对应；所用 LVGL API 已对照该版本声明核对。
- 使用所分发字体的字形宽度和字距数据检查正常读数及较长数字的字号缩放。生成的排版检查图仅为源码布局辅助检查，不是 LVGL 运行截图或实机验证。
- 代码中充电流光需要有效 BMS 数据、电流小于 -0.2 A 且无保护标志；流光不会改变 SOC 长度或读数。
- 关闭/暂停流光不影响数据采集。断线/超时由既有快照有效性判断处理，界面恢复占位读数。
- 本次没有增加开机动画、延时展示或新的启动页面。

尚待用户自行上板确认：Arduino 环境兼容性、实际字体/颜色/布局、动画帧率、BLE 与动画同时运行的表现、侧键操作、连接/断线/超时状态、充放电符号与手机 App 是否一致。
